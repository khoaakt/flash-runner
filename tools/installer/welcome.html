flash-runner

This installs two things:

  • The extension, as a folder in @EXTENSION_DIR@.
  • The online game helper, which games need to reach their own servers. It is selected by default, and registered for every Chromium-family browser on this Mac.

The installer cannot switch the extension on for you: Chrome only accepts extensions from outside the Chrome Web Store when you add them yourself. The last page lists the three clicks.
